# 建筑复核示例图片

本目录包含三栋TUM2TWIN建筑的9个已归档测试视角，每个视角包含参考照片和CW-DepthGS渲染，共18张PNG。

素材来自项目保留的定性对比板。生成脚本按对比板原始布局提取第1列参考照片及第3列CW-DepthGS结果，去掉顶部标签。没有重绘、补全、放大或改变图像内容。每张图片宽480像素；这部分网页用于已渲染视角的查看与人工记录，不是连续三维场景查看器，也不提供工程量测。

对比板列序为参考照片、固定深度、CW-DepthGS、固定深度误差、CW-DepthGS误差，不包含RGB-only。已有选图按两种方法的PSNR差值选择最好、中位、最差视角，网页使用测试视角编号显示；具体选择和裁剪框记录在manifest.json中。仅保存已有测试视角的图像，未附带原始数据全集。

可复现提取脚本：prepare_showcase_cases.py。数据来源：https://tum2t.win 。
