# CW-DepthGS 建筑外观建档与复核

公开网站：<https://yangxinyi105.github.io/cw-depthgs-showcase/>

网站包含本机照片复核、三维模型浏览、项目档案入口和研究说明。已发布的照片与模型直接由静态网站提供，展示不依赖训练服务器开机。

## 是否需要运行服务器

| 功能 | 训练服务器关闭后 |
|---|---|
| 首页、实验、技术报告、照片复核 | 仍可使用 |
| 已发布建筑模型的旋转和缩放 | 仍可使用，在访问者浏览器中渲染 |
| 本地照片、模型读取及本地导出 | 仍可使用 |
| 项目档案、上传、共享记录同步 | 需要配置的后端服务在线 |
| 新建筑的3DGS训练 | 需要另行启动训练环境 |

项目档案前端不会自动启动服务器。`service-config.js` 只允许填写公开API地址，不能填写密钥。当前默认地址留空，管理员可在档案页连接已部署的服务；未连接时不会把本机记录冒充云端保存。

## 三维浏览

`viewer.html` 可打开建筑4906981的真实训练结果精简版，或读取本机标准 `.splat` 文件。模型按需下载，不会在进入首页时自动加载。公开展示版保留80万个高斯点和SH0颜色，来源与转换记录在 `assets/models/`；正式实验指标对应完整训练模型。

鼠标拖动旋转、滚轮缩放、右键拖动平移，页面也提供旋转与缩放按钮。渲染依赖浏览器WebGL 2及设备性能，不使用服务器GPU。

## 项目档案服务

`archive.html` 连接独立的后端，可建立建筑档案、上传照片和模型、保存二维标注、生成只读分享链接和打印复核记录。管理密钥只保留在当前浏览器会话中；分享链接使用独立的只读令牌，查看者无需登录。记录人名称由编辑者填写。

多人编辑采用版本检查：如果另一位成员已更新资料，保存会提示冲突并保留本页草稿，用户可下载草稿，再刷新比较。照片和模型随档案存储在后端磁盘，数据库保存项目与标注。后端实现及部署、备份说明位于私有代码仓库 `web-backend/`，采用FastAPI、SQLite和文件存储，无需GPU。正式外网访问需要独立HTTPS地址。

## 使用

1. 在首页选择公开建筑和视角，对照参考照片与重建渲染。
2. 点击渲染图添加标注，填写备注后点击“保存标注”。可以将状态改为“已复核”。
3. 填写可选的资料名称和采集日期，下载当前视角的标注 PNG，或生成全部视角的打印报告。浏览器打印可保存为 PDF。
4. 下载 JSON 档案备份标注，在另一台设备上导入以恢复记录。
5. 处理现场资料时，点击“选择本地现场照片”，一次选择不超过 20 张 JPG、PNG 或 WebP，每张不超过 20 MB。照片仅在浏览器中打开，不上传服务器。

标注保存在当前浏览器的本地存储中。清除浏览数据会移除本机记录。JSON 包含资料名称、日期、二维标注和备注，**不包含照片文件**；交接时应同时保存或提供原始照片。恢复现场照片的档案时，先选择相同的原始照片，再导入 JSON。系统按照片内容指纹匹配，修改照片内容后会视为新照片。

## 范围

- 展示的是三个 TUM2TWIN 公开建筑的 9 个已生成测试视角，来源与裁剪记录见 `assets/cases/README.md` 和 `manifest.json`。
- 网站提供图像对照、人工标注、三维模型查看和导出；现场照片导入不会执行重建。离线 3DGS 训练仍需在独立计算环境中完成。
- 标注使用二维图像坐标，不提供真实尺寸测量或自动病害识别。项目档案通过保存和刷新协作，不提供多人实时光标或自动合并。
- 公开案例用于演示工具与实验结果。现场维修判断应结合原始照片及专业复核。

## 研究内容

`research.html` 保留方法、固定视角实验设计、多随机种子结果、模块消融及局部校准实验。旧首页的研究锚点会转到研究页。

## 本地运行

本目录是可独立托管的静态前端；项目服务需另行运行，展示功能无需启动后端。

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。请通过本地 HTTP 服务访问，直接双击 HTML 时浏览器可能阻止读取案例清单。生产环境使用 HTTPS，确保本地照片内容指纹功能可用。

## 文件

- `index.html` / `application.css`：应用首页。
- `workspace.js` / `workspace.css`：照片对照、记录和导出。
- `archive.html` / `archive.js` / `archive.css`：连接持久化项目档案服务。
- `viewer.html` / `viewer.js` / `viewer.css`：WebGL三维高斯模型浏览。
- `vendor/`：固定版本的浏览器依赖与许可证。
- `assets/cases/`：公开演示图像与来源清单。
- `research.html` / `styles.css` / `app.js`：研究展示。
- `assets/technical-report.pdf`：技术报告。
